# digital-bypass

**Мультитул для обхода блокировок на Windows**

zapret2 (winws2 + Lua) в один клик, прокси-обходчик без прав администратора, смена DNS и DoH, проверка «почему не открывается», hosts.

## Модули

### zapret2

- **Встроенный zapret-discord-youtube.** Сборка лежит внутри установщика, при обновлении ваши списки и настройки остаются. Можно указать свою папку.
- **Включение в один клик.** `winws2.exe` запускается напрямую, без консоли: процессом (пока открыто приложение) или службой `zapret`, совместимой с `service.bat`.
- **Стратегии без переделок.** Аргументы берутся прямо из `general*.bat`.
- **Тесты стратегий** по образцу `utils\test zapret.ps1`: HTTP / TLS 1.2 / TLS 1.3 + ping и DPI-тест «16-20 КБ», выбор лучшей, история.
- **Автоподбор стратегии** (эксперимент, по мотивам [Geneva](https://geneva.cs.umd.edu/)): лучшие стратегии мутируются (техника, `pos`, `seqovl`, `repeats`, порча пакетов, фейк — значения берутся из стратегий сборки), каждый кандидат проверяется тестером дважды с худшим результатом, при равенстве побеждает более простой. Лучший, если он обошёл исходные, сохраняется как `general (AUTO N).bat`. Это упрощённый локальный поиск, а не полный генетический алгоритм: без скрещивания и популяции.
- **Авто-стратегия**: из лучших стратегий теста собирается одна, в которой winws2 сам переключает варианты для каждого сайта при сбоях (`circular` из `zapret-auto.lua`).
- **Дополнения** (из сборки bol-van): разблокировка WireGuard/AmneziaWG, экономный перехват UDP фильтрами в драйвере (меньше нагрузка при видео и звонках), скрытие WinDivert от античитов.
- **Game Filter, IPSet, пользовательские списки** — те же файлы, что пишет `service.bat`.
- **Наборы доменов**: Telegram, Instagram/Facebook/WhatsApp, X, Roblox, SoundCloud добавляются в список одним кликом (YouTube и Discord уже есть во встроенных списках).

### DNS

Иногда лёгкие блокировки обходятся одной сменой DNS.

- Выбор сетевого адаптера. Адаптер, через который идёт интернет, выбирается сам.
- Текущие DNS для IPv4 и IPv6: заданы вручную или получены по DHCP, включён ли DoH.
- Пресеты: Cloudflare, Cloudflare Security, Google, Quad9, AdGuard, AdGuard Unfiltered, Яндекс, Яндекс Безопасный, OpenDNS, Mullvad. Или свои адреса.
- **DNS-over-HTTPS** (Windows 11): шаблон регистрируется через `netsh dns add encryption`, на адаптере включается шифрование для выбранных серверов. Откат на обычный DNS — по желанию.
- Возврат к автоматическому DNS (DHCP) и сброс кэша DNS.
- **Локальный резолвер** — шифрованный DNS и на Windows 10: приложение само отвечает на DNS-запросы на `127.0.0.x:53` и пересылает их по DoT (DNS поверх TLS, работает у всех пресетов, кроме OpenDNS) или DoH. Пока оно работает, провайдер не видит и не подменяет DNS; при выходе прежний DNS возвращается. Есть резервный обычный DNS на случай, если приложение закрыто. Резолвер **убирает ключи ECH**: на запросы HTTPS-записей отвечает пусто, и браузер шлёт обычный ClientHello вместо отбрасываемого ТСПУ `cloudflare-ech.com` — сайты за Cloudflare снова обходятся нарезкой (если у браузера выключен собственный «безопасный DNS»).

### Прокси-обходчик

Обход DPI **без прав администратора и без драйвера** — для рабочих ПК и случаев, когда антивирус не даёт WinDivert.

- Локальный прокси режет TLS ClientHello: по имени сайта, первый байт, куски заданного размера, в случайной точке или по своим позициям (синтаксис ByeDPI, например `0+sm 1:3:5 -10`); части — отдельными TLS-записями или TCP-сегментами. `disorder` отправляет первую часть с TTL=1.
- **Автоматический режим**: если сайт сбросил соединение или молчит после ClientHello, прокси переподключается запасными способами и запоминает рабочий для этого сайта. **OOB** — к первой части добавляется «срочный» байт, который видит DPI, но не сервер. Идеи — из [ByeDPI](https://github.com/hufrea/byedpi).
- **Журнал соединений** (по желанию): сайт, что сделано, каким способом, сколько попыток и чем кончилось.
- **Подбор способа**: каждый вариант нарезки проверяется на временном прокси по выбранным сайтам, лучший применяется одной кнопкой — как тесты стратегий zapret2.
- **Правила по доменам**: резать всё или только домены из списков (в том числе списков zapret2), «не резать» для банков и капризных сайтов, блокировка.
- Адреса сайтов разрешаются через DoH (Cloudflare и Google параллельно, с кэшем) — подмена DNS не мешает. Подключение идёт сразу к нескольким адресам сайта, побеждает первый ответивший.
- Прокси прописывается в настройки Windows и снимается при выключении.
- HTTP и SOCKS5 на одном порту.
- **Раздача в локальную сеть**: телефон в той же Wi-Fi указывает ПК как прокси. Пускаются только адреса локальной сети, правило брандмауэра добавляется само (с правами администратора). Можно задать логин и пароль — их спрашивают у устройств из сети, но не у самого ПК.
- **Маленький буфер приёма** (эксперимент): сервер присылает ответ мелкими кусками — против DPI, который режет по сертификату в ответе, где нарезка запроса бессильна. Аналог `--wssize` из zapret без драйвера.
- **Разные версии TLS-записей**: первая запись с версией 1.2, остальные 1.0 — ещё один способ сбить DPI, разбирающий только первую запись (по мотивам [CircumVolve](https://doi.org/10.1145/3830454.3846759)).
- Только HTTPS через прокси: UDP, QUIC и голос Discord по-прежнему требуют zapret2.

### Telegram

Локальный MTProto-прокси для Telegram Desktop — порт [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) (Flowseal, MIT). Трафик идёт через WebSocket к веб-адресам Telegram; если они недоступны — через свой Cloudflare Worker или CF-прокси (домены за Cloudflare), в крайнем случае — напрямую по TCP. TLS к Telegram и Cloudflare открывается с нарезкой ClientHello, как в прокси-обходчике; для прямого маршрута можно подменить SNI (например, на имя из белого списка). Подключение в Telegram — одной кнопкой (ссылка `tg://proxy`). Сообщения остаются зашифрованными MTProto.

### Проверка

Введите домен — приложение сравнит системный DNS с DoH, попробует TCP и TLS к каждому адресу и скажет, в чём дело: подмена DNS, DPI по имени сайта или блокировка по IP. И подскажет, какой модуль поможет.

Если прокси-обходчик включён, сайт проверяется и через него: видно, исправляет он сайт или ломает. Отдельно распознаётся **ограничение по сети назначения**, которым с 2025 года режут зарубежные хостинги: TLS к адресу обрывается с любым именем сайта или передача замирает после ~16–33 КБ. Нарезка тут не помогает.

Если режет DPI, проверка уточняет, как именно (методика blockcheck из [zapret](https://github.com/bol-van/zapret)): на запросе (сервер не успел ответить — поможет нарезка) или на ответе сервера (сертификат — поможет маленький буфер приёма или zapret2); открывается ли сайт с нарезкой; режется ли сам адрес с другим именем (частичная блокировка по IP) и режется ли имя на постороннем адресе. Каждый адрес проверяется дважды: расхождение — признак балансировки или нескольких DPI, засчитывается худший результат.

**Подмена DNS**: находит заглушки провайдера (127.0.0.1 и чужие адреса на заблокированные домены) и перехват запросов к 8.8.8.8, 1.1.1.1, 9.9.9.9 — тогда смена DNS не помогает и нужен зашифрованный. Эталон — DoT; отличающиеся адреса проверяются сертификатом сайта (с нарезкой ClientHello, чтобы не мешал DPI).

**Сканер SNI** отправляет к одному адресу TLS-приветствие с разными именами сайтов и показывает, какие имена DPI пропускает. Помогает понять, включены ли белые списки, и подобрать имя для VLESS Reality или поддельный SNI для стратегий. Идея — из [sni-spoofing-rust](https://github.com/therealaleph/sni-spoofing-rust).

### hosts

Записи из `.service\hosts` добавляются в системный hosts отдельным блоком, который снимается одной кнопкой. Свои записи, обновление с GitHub, бэкап перед записью.

### Общее

**Включение по сети** (как `--ssid-filter` в winws): zapret2 и прокси работают только в выбранных сетях или везде, кроме них. Сеть определяется по имени профиля Windows (для Wi-Fi — имя сети), при смене сети обход останавливается или возвращается.

**MCP для ИИ-ассистентов** (Настройки → MCP, выключено по умолчанию): Claude, Cursor и другие клиенты MCP подключаются к приложению по `http://127.0.0.1:8899/mcp` с токеном. Скажите ассистенту «почему не грузится Discord» — он вызовет `diagnose_site` (DNS, TCP, TLS, на чём режет DPI) и, если нужно, `find_zapret_strategy` (перебирает стратегии zapret2 именно для этого сайта). Есть и статус, журналы прокси и winws2, проверка DNS, результаты тестов. Менять настройки (включать zapret2 и прокси, выбирать стратегию, править списки) ассистент может, только если включено «Разрешить изменения».

Трей с быстрым включением zapret2 и прокси-обходчика, сменой стратегии и состоянием DoH-резолвера, автозапуск с правами администратора, русский и английский интерфейс.

## Установка

1. Скачайте `digital-bypass_x.y.z_x64-setup.exe` со страницы [Releases](https://github.com/digital-bombyx/digital-bypass/releases/latest) и установите. Рядом лежит `.sha256`.
2. Запустите. Приложение попросит права администратора: они нужны WinDivert, службам, hosts и смене DNS.

> [!NOTE]
> Внутри лежат `winws2.exe` и драйвер WinDivert. Некоторые антивирусы помечают такие файлы как угрозу. Проверить их можно по контрольным суммам релиза [zapret2](https://github.com/bol-van/zapret2/releases).

## Сборка из исходников

Нужны Node.js, Rust (MSVC) и git-клон [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube):

```powershell
npm install
$env:ZAPRET_SRC = "D:\zapret-discord-youtube"   # по умолчанию именно этот путь
npm run tauri build
```

Перед сборкой `scripts/sync-zapret.mjs` берёт чистую копию сборки из git и кладёт её в ресурсы установщика. Установщик появится в `src-tauri\target\release\bundle\nsis\`.

Релизы собирает GitHub Actions ([`release.yml`](.github/workflows/release.yml)) при пуше тега `vX.Y.Z`, описание берётся из [CHANGELOG.md](CHANGELOG.md).

### Идеи

Код ниже — свой, из этих проектов взяты приёмы и подходы:

- **[ByeDPI](https://github.com/hufrea/byedpi)** (hufrea) — автоматический режим прокси, OOB, синтаксис своих позиций разреза.
- **[SpoofDPI](https://github.com/xvzc/spoofdpi)** (xvzc) — способы нарезки, правила по доменам, кэш DNS.
- **[NoDPI](https://github.com/GVCoder09/NoDPI)** (GVCoder09) — проверка домена, прокси без прав администратора, DoH на Windows 10, наборы доменов.
- **[GreenTunnel](https://github.com/SadeghHayeri/GreenTunnel)** (Sadegh Hayeri) — DNS-over-TLS, журнал соединений.
- **[sni-spoofing-rust](https://github.com/therealaleph/sni-spoofing-rust)** (therealaleph) — сканер SNI, раздача в локальную сеть.
- **[Geneva](https://geneva.cs.umd.edu/)** (Bock et al., ACM CCS 2019) — подход автоподбора: засев известными стратегиями, оценка с повторами, штраф за сложность, зал славы.
- **[B4](https://github.com/DanielLavrushin/b4)** и **[tspu-docs](https://github.com/DanielLavrushin/tspu-docs)** (DanielLavrushin) — удаление ключей ECH из DNS, проверка «напрямую и через обход», поиск SNI для хостингов, подтверждение победителя; сведения о том, как ТСПУ ограничивает хостинги.
- **[zapret](https://github.com/bol-van/zapret)** (bol-van) — методика blockcheck для определения типа блокировки, маленький буфер приёма (аналог `--wssize`), включение по сети (`--ssid-filter`).

Бинарники и Lua-скрипты встроенной сборки распространяются под лицензиями их авторов (см. `LICENSE.txt` в папке сборки).
